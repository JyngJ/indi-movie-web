## 5. 광고

방식: **AdSense 자동 광고**. 슬롯을 직접 배치하는 대신 AdSense 광고 설정 미리보기에서 형식을 고른다. 처음 계획한 위치별 수동 배치(소식탭 배너 · 피드 중간 슬롯)는 보류.

- 게시자 ID `pub-9133958847616613`. `ads.txt` 배포됨(#366). 사이트 승인 전
- 사이트 코드: 루트 `layout.tsx` `<head>`에 `adsbygoogle.js?client=ca-pub-…` 스크립트 1줄. **아직 미삽입.** 승인 크롤러가 찾도록 `next/script`가 아닌 서버 렌더 `<script async>`로 넣는다(JSX는 `crossOrigin`)
- 자동 광고 설정(미리보기 기준): 인페이지 1/2, 오버레이 0/3(앵커가 하단 탭바와 겹침), 의도 기반 0/1
- 전면광고를 켜면 Search Console 모바일 노출·클릭을 2~3주 관찰
- 심사 리스크: "스크랩된 콘텐츠" 정책. 지도 재구성·큐레이션·랭킹이 방어 근거

### 자동 광고 주의

- 자동 광고는 전체 페이지 로드 때 배치한다. Next 클라이언트 이동에서는 재배치되지 않는다
- 인페이지 광고는 AdSense가 DOM에 직접 끼워 넣는다. React가 그 구간을 다시 그리면 `removeChild` 오류가 날 수 있다. 지도 화면은 "제외된 페이지" 후보. 삽입 직후 상세↔목록 이동을 반복해 콘솔 오류를 확인한다
- 수동 슬롯으로 돌아가면: 고정 높이(CLS), "광고" 라벨 필수
- EEA 트래픽은 AdSense "개인정보 보호 및 메시지"의 Google 동의 메시지로 처리
