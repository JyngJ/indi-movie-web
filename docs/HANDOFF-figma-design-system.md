### 피그마 동기화 파이프라인 (이게 핵심이다)

Figma 플러그인 **Scripter**로 스크립트를 돌려 코드↔시안을 양방향 동기화한다.
스크립트는 전부 `scripts/figma/*.js`에 커밋돼 있다. 에이전트가 직접 피그마를 못 만지므로
**스크립트를 짜서 사용자에게 "이거 돌려줘"라고 링크로 건네는 방식**으로 일한다.
파일 경로는 마크다운 링크로 보낼 것 — 클릭해서 열 수 있다.

**덤프로 현재 상태를 읽는다.** 사용자가 Scripter에서 `dump-state`를 돌리면
`~/.claude/skills/figma-scripter-sync/figma-dump/state.json`에 파일 전체가 떨어진다
(노드 트리·오토레이아웃·색/변수 바인딩·텍스트 스타일·이펙트 전부). 수신 서버는
`~/.claude/skills/figma-scripter-sync/dump-receiver.py`이고 이미 상시 떠 있다.
**추정하지 말고 항상 덤프를 읽고 실측으로 말할 것.**

덤프 JSON은 3.5MB다. 통째로 읽지 말고 python으로 필요한 노드만 뽑아 봐라.

### 반복해서 밟은 함정 (같은 실수 하지 말 것)

`scripts/figma/_pin-common.md`에 정리돼 있다. 요약하면:

1. **색은 시멘틱 컬렉션에서 찾는다.** 토큰 3계층 — `영화볼지도 색상 - 2.0`(원시값) →
   `영화볼지도 시멘틱 - 2.0`(역할) → 코드 `--comp-*`. 컴포넌트를 그릴 땐 2계층을 쓴다.
   1.0 시절 `Primitives`·`Semantic` 컬렉션은 삭제했다(같은 이름이 값만 달라 사고가 반복됐다).
2. **꼬리는 11×11 정사각 rotate45**(지역 힌트 팝업 문법). `rotation`은 좌상단 원점 기준이라
   계산한 좌표가 어긋난다 — 붙인 뒤 `absoluteBoundingBox`로 중심을 보정해야 한다.
3. **섹션 자식의 x/y는 페이지 절대 좌표다.** 섹션 안에 루트 오토 레이아웃 프레임 하나를 두고
   그 안에 쌓아라. 좌표를 만지는 곳은 루트 한 곳뿐이어야 재실행해도 배치가 흐트러지지 않는다.
4. **프레임→컴포넌트는 `createComponentFromNode`.** 자식만 새 컴포넌트로 옮기면 패딩·fill·
   radius가 날아간다.
5. **절대 위치의 기준 블록은 border box가 아니라 padding box다.** 패딩 있는 카드 안에
   `top:-8`을 주면 카드 밖이 아니라 안쪽에 찍힌다. 코너 배지는 패딩 없는 래퍼에 형제로 둬라.
6. **스크립트는 단계마다 독립 `try/catch`로 짜고 콘솔에 `완료:`/`실패:`를 남겨라.**
   한 단계가 죽으면 아무것도 반영 안 되는 스크립트를 두 번 만들었다.

### 미결

- **`2.0/badge` 텍스트 스타일이 없다.** 배지는 10/Bold인데 `2.0/label`이 Medium이라
  스타일을 링크하면 얇아진다. 지금은 Bold를 직접 지정 중. 스타일을 파든 코드를 500으로
  낮추든 정해야 한다.
- **`TheaterSheet.tsx`가 2500줄이 넘는다.** 드래그·필터·UI로 쪼개는 게 오래된 부채고,
  이번 작업으로 오히려 늘었다.
- 지도 핀 코드 이식은 끝났지만 **일정 모드(단일 영화 필터)와 GV 다건 `+N`은 화면으로 확인 못 했다.**
  로컬 데이터에 해당 케이스가 없어서다.
- 헤드리스 브라우저로 **호버·스크롤 애니메이션은 검증이 안 된다**(패널이 백그라운드라
  포인터 이벤트와 `requestAnimationFrame`이 안 돈다). 그런 건 사용자에게 확인을 요청할 것.

### 일하는 방식

- 사용자는 한국어로 짧게 지시한다. 답도 한국어로, 군더더기 없이.
- **덤프 없이 "아마 이럴 것"이라고 말하지 말 것.** 이 작업에서 사고는 전부 추정에서 나왔다.
- 스크립트를 고칠 때는 **브랜치를 옮긴 직후인지 확인해라.** 낡은 사본에 수정을 얹어
  하이브리드를 만든 적이 있다.
- 커밋 메시지는 한국어 본문으로, **무엇을 왜 바꿨는지**를 적는다. 파일 목록 나열 금지.
