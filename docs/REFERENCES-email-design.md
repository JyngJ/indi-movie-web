## 발송 구성

1. 브랜드 헤더 이미지
2. 관심 항목의 새 상영·막바지 상영
3. 이번 주 이런 상영도 있어요 — 발송일~일요일, 지역 설정 반영, 앞 섹션 영화 제외, 영화별 중복 제외, 최대 3편. 조건에 맞는 영화가 없으면 섹션 생략
4. 다른 상영 구경하러 가기 → `/films`
5. 브랜드 푸터 이미지 + 수신 해지·설정·개인정보 링크

영화의 ‘예매하러 가기’는 `/movie/:id?tab=theaters`로 연결한다. 기존 상세 화면의 상영 목록으로 스크롤한 뒤 회차를 선택하고 예매 사이트로 이동한다. 여러 회차 중 임의의 외부 예매 링크로 보내지 않는다.

주간 섹션은 기존 관심 소식 메일에만 추가한다. 추가 섹션만으로 발송을 만들거나 빈도를 늘리지 않는다. 자동 발송 활성화·배포는 이번 작업에 포함하지 않는다.

## 라이팅 스킬 반영 — 2026-10-20

사용자가 제공한 `ux-writing-ko.zip`의 SKILL.md와 component-patterns·korean-expression·finance-payments를 읽고 적용했다. 프로젝트의 해요체·띄어쓰기 규칙은 유지한다.

확인한 기준:
- “지웠을 때 잃는 정보가 없는 문장은 빈 문장이다”
- “설명은 제목에서 빠진 이유·조건·결과를 보완한다”
- “버튼으로 바로 다음 단계를 예측하게 한다”

| 원문 | 수정 | 이유 |
|---|---|---|
| 좋아하는 영화의 소식, 여기로 보내 드릴게요 | 이메일을 인증해 주세요 | 인증 메일에서 필요한 행동을 먼저 제시 |

| 이번 주에 볼 수 있는 다른 영화예요 | 삭제 | 바로 위의 ‘이번 주 이런 상영도 있어요’와 중복 |
| 다음에 볼 영화를 찾아볼까요? | 삭제 | 하단 링크와 같은 행동을 반복하는 질문 |
| 다음 영화도, 극장에서 만나요 | 삭제 | 기능·조건을 추가하지 않는 푸터 문구 |

브랜드 헤더·푸터를 `header-v2.png`·`footer-v2.png`로 교체했다. 점선 장식과 색면 배너를 제거하고 로고·메일 종류·구분선으로 구성한다. 인증 후 받는 내용·월/금 9시·새 소식이 있는 경우에만 발송하는 조건·링크 1시간 유효 안내는 유지한다.

영화별 ‘예매하러 가기’는 사용자가 지정한 문구를 유지했다. 실제 다음 화면은 영화의 상영 목록이며, 그곳에서 극장·회차를 선택한다.

## 관심 유형별 묶음 — 2026-10-20

메일 제목과 본문 제목은 ‘관심 영화·감독·극장의 상영 소식’으로 통일했다. 관심 영화는 극장·일정이 있는 가로 목록, 관심 감독·극장은 해당 이름 아래 포스터·제목·감독의 2열 카드로 묶는다. 카드의 포스터·제목은 영화의 상영 목록으로, 묶음 하단은 감독·극장의 전체 상영으로 이동한다. 소식에 포함된 실제 영화 목록을 보존하며 주간 추천에서 이 영화들을 제외한다. 예시 이미지의 극장·영화 조합은 배치 확인용이며 실제 상영표가 아니다.

## 제목과 행사 소식 — 2026-10-20

로고 오른쪽 ‘상영 소식’을 제거했다. 본문 전체 제목은 h1 24px, 분류 제목은 h2 20px·브랜드 색·600으로 구분한다. 메일 제목은 실제 포함된 관심 영화·감독·극장의 대표 소식으로 생성한다: `🎬 영화 상영해요, 감독의 영화가 상영해요, 극장에서 영화 상영해요`. 없는 유형은 제목에서 생략한다.

GV·특별전은 다음 연동 후보로 남긴다. 관심 극장 묶음에서 영화 카드 위에 행사명·날짜·시간·확인된 참석자를 표시한다. 확정·취소·종료 상태와 극장 식별을 확인하고 행사별 발송 이력으로 중복을 막아야 한다. 현재 GV 타입에는 theaterId·eventDate·guest가 있으나, 특별전의 기간·출처·극장 연결과 메일 발송용 저장소 연동은 아직 검증하지 않았다. 따라서 현 메일에 행사를 자동으로 포함한다고 안내하지 않는다.

Gmail 발신자 가이드 https://support.google.com/mail/answer/81126?hl=ko 에서 링크 개수에 따른 고정 스팸 기준은 확인하지 못했다. 발신 인증·수신 동의·쉬운 해지·신고율·오해 없는 제목 및 링크가 주요 확인 항목이다. 스팸 미분류를 보장하지 않는다.
